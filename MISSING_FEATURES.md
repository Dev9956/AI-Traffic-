**Target Systems:** Proposed Advanced Upgrades  
**Evaluator:** Senior AI Architect

## 1. Evaluation Matrix

| Proposed Feature | What Already Exists | What Is Missing | Reusable Modules | Dev Complexity | Performance & Practical Value | Worth Implementing Now? |
|---|---|---|---|---|---|---|
| **1. Indian Traffic Classification (Auto-rickshaws, Motorcycles)** | `classes.py` maps `bike` -> `motorcycle`. Model has 7 classes (`car`, `bus`, `truck`, `bike`, `ambulance`, etc.). | YOLOv11m weights (`best.pt`) are trained on CARLA European/US vehicles. No `auto_rickshaw` class or e-rickshaw data in model training. | `cv_pipeline/classes.py`, `yolov11_detector.py`, `types.py` (`VehicleType` enum). | **Medium** (Fine-tuning YOLO weights on Indian traffic dataset, e.g. IDD). | **High** in heterogeneous traffic contexts; captures 60%+ of urban vehicle volume. | **Yes** (Model fine-tune only; zero architecture change). |
| **2. Congestion Prediction (5–15 min forward)** | `metrics.py` calculates rolling 60s queue counts, throughput, and average wait time. Tick data is buffered at 10 Hz. | No time-series forecasting model (LSTM, GRU, or ARIMA) predicting incoming queue volumes $t + \Delta t$. | `packages/shared/shared/types.py`, `db_service.py` (reads past tick logs), `metrics.py`. | **Medium** | **High**: Allows proactive signal phase allocation before queues spill over. | **Yes** (Lightweight Linear / Ridge or Tiny-GRU on tick history). |
| **3. Multi-Intersection Emergency Corridor** | BFS pathfinder (`ev_routing.py`) finds multi-hop node list (`['A0', 'B0', 'C0']`). `preemption.py` truncates signal. | Corridor preemption only activates on the *currently approached* intersection. Next intersections along the route do not cascade green preemption in advance. | `ev_routing.py`, `preemption.py`, `emergency.py`, `activeEvRoutes` store in frontend. | **Low** | **Very High**: Guarantees true non-stop Green Wave across 3–5 intersections. | **Yes (Top Priority)**: Reuses existing BFS pathfinder with minor preemption loop extension. |
| **4. Historical-Data AI Traffic Analyst** | `routers/chat.py` with Groq (`llama-3.3-70b-versatile`). `_build_system_prompt()` injects live tick snapshot. | LLM prompt only receives current instantaneous snapshot. It does not query historical runs, race comparisons, or Supabase metric tables. | `routers/chat.py`, `services/db_service.py`, `services/experiment_service.py`. | **Low** | **High**: Allows user to ask "Compare today's rush hour vs yesterday" or "Why did intersection B1 fail at 14:00?". | **Yes (Top Priority)**: Integrate existing `db_service.get_run_global_metrics()` into chat prompt. |
| **5. Pedestrian Detection & Crossing Priority** | Signal state supports arbitrary phase masks. Virtual regions support polygon geometry. | No pedestrian class in YOLO model, no crosswalk polygon regions, no pedestrian phase triggers in `ActuatedController`. | `regions.py` (polygons), `yolov11_detector.py` (COCO class 0 is person), `actuated.py`. | **Medium** | **Medium**: Useful for urban intersections with pedestrian safety goals. | **Defer**: Needs network crosswalk annotations in SUMO `.net.xml`. |
| **6. Wrong-Way & Safety Violation Detection** | `approach_analyzer.py` calculates smoothed speed vectors and world coordinates $(x, y)$. | Only checks Red-Light crossing. No directional vector angle check or threshold speed violation check ($v > v_{\text{limit}}$). | `approach_analyzer.py` (`_SpeedTracker`), `regions.py` (`ViolationDetector`), `classes.py`. | **Low** | **Very High**: Immediate safety monitoring enhancement with zero extra models required. | **Yes (Top Priority)**: Compare velocity heading vector against lane heading angle. |
| **7. Controller Reliability & Fail-Safe Mechanisms** | `actuated.py` has fallback defaults if queues are zero. Error handling wraps TraCI calls. | If camera feed drops or YOLO detector crashes, actuated controller has no graceful fallback to default fixed-time cycle. No heartbeat watchdog. | `simulation_service.py`, `actuated.py`, `fixed_time.py`. | **Low** | **Critical**: Production requirement to prevent signal freeze or deadlocks. | **Yes (Top Priority)**: Add watchdog timer that reverts to `FixedTimeController` upon CV timeout. |
| **8. Multi-Agent RL (MAPPO)** | Clean decoupled policy interface: takes `IntersectionState` list, returns `SignalCommand` list. | No RL environment wrapper (Gym/PettingZoo), no actor-critic network, no training replay buffer or reward function. | `packages/adaptive-policy/adaptive_policy/` abstract interface. | **High** (Training divergence risk, compute intensive, complex debugging). | **Medium** (Marginal wait-time gains over tuned actuated heuristics in small grids). | **No / Defer**: Actuated policy already achieves -54% wait time; RL brings high maintenance burden. |
